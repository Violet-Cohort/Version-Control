# Command Line Prompts

1. pwd: print working directory
1. ls: List 
1. cd: Change directory
1. clear: Clears the screen
1. mkdir: Make directory
1.touch: to create files
1. rm: To delete a file
1. rem -rf: To delete a folder and its content

# Git Commands

1. git init: To initialize
1. git status: To check the status of a repo
1. git add: To stage
1. git branch: TO list all the branches
1. git checkout: To switch a branch
1. git checkout -b name of branch: TO create a new branch
